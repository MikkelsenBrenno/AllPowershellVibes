# Remote-Work

Intune Platform Scripts packages for VPN, Wi-Fi, Teams, OneDrive, remote access readiness, M365 connectivity, and home-office support workflows.

Use this category when technicians need scripts that are easier to find by browser or remote-work scenario rather than a broader application, networking, or user-experience bucket.

## Folder Pattern

``text
Intune-Platform-Scripts/Remote-Work/<Script-Name>/
``
