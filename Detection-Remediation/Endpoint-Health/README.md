# Endpoint Health

Detection and remediation packages for Intune Management Extension health, enrollment health, Defender health, WMI health, service health, and management agent repair.

Use this category when the script validates that the endpoint can be managed and monitored correctly.

## Scripts

| Script | Purpose |
| --- | --- |
| `Disk-Detect-Predictive-Failure` | Detects SMART predictive failure or unhealthy disk state for the Windows disk and optionally alerts from remediation. |

## Folder Pattern

```text
Detection-Remediation/Endpoint-Health/<Script-Name>/
```
