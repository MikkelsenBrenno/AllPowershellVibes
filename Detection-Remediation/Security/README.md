# Security

Detection and remediation packages for security hardening, Microsoft Defender settings, firewall controls, attack surface reduction, local administrator controls, and other security baselines.

Use this category when a security setting should be checked repeatedly and corrected when it drifts.

## Folder Pattern

```text
Detection-Remediation/Security/<Script-Name>/
```

## Scripts

| Folder | Purpose |
| --- | --- |
| `Defender-Enable-Behavior-Monitoring` | Enables Microsoft Defender behavior monitoring |
| `Defender-Enable-Cloud-Protection` | Configures Microsoft Defender cloud protection and sample submission behavior |
| `Defender-Enable-Network-Protection` | Enables Microsoft Defender Network Protection |
| `Defender-Enable-PUA-Protection` | Enables Microsoft Defender potentially unwanted application protection |
| `Defender-Enable-Real-Time-Protection` | Enables Microsoft Defender real-time protection |
| `Defender-Enable-Script-Scanning` | Enables Microsoft Defender script scanning |
| `Firewall-Enable-All-Profiles` | Enables Windows Firewall for Domain, Private, and Public profiles |
